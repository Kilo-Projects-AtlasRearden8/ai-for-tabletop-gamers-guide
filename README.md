# AI for Tabletop RPGs and Board Games

A beginner-friendly manual and static site for using free AI with tabletop
roleplaying games and board games: character sheets, campaign notes, NPC ideas,
rule clarifications, and session prep. Step-by-step prompts, printable
worksheets, and privacy rules included. Education only — no game assets.

## Who this is for

This guide was written by Dylan Asdale, a registered nurse turned AI author and
founder of **Asdale Dynamics, LLC** (Indiana, formed October 2026). It follows
the same plain-English, step-by-step, never-condescending style as his book
*The Massive AI Manual* and hub site dylanasdale.github.io: AI explained "like a
friend would."

It is for anyone who plays D&D, Pathfinder, Call of Cthulhu, board games, or
any tabletop game and wants a helpful, free AI assistant at the table — no
coding required, no technical background assumed.

## What's inside

- `docs/` — the full beginner manual in Markdown
- `site/` — a static HTML version of the manual (works offline, no build step)
- `site/worksheets/` — printable character and session worksheets
- `LICENSE` — MIT License, Copyright (c) 2026 Asdale Dynamics, LLC

## How to read it

Start with `docs/00-intro.md` or open `site/index.html` in any web browser.
No server, no install, no account required to read the guide itself.

## Privacy

See `docs/09-privacy-and-safety.md` and `site/privacy-and-safety.html` for
privacy rules and safety guidance. This guide never asks for your personal data
and contains no API keys or secrets.
