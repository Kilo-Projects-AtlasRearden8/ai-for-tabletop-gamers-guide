# AI for Tabletop RPGs and Board Games

A beginner-friendly manual and static website for using free AI with tabletop
roleplaying games and board games: character sheets, campaign notes, NPC ideas,
rule clarifications, session prep, and board game help. Step-by-step prompts,
printable character and session worksheets, and privacy rules included.
Education only — no game assets.

## Who this is for

This guide was written by Dylan Asdale, a registered nurse turned AI author and
founder of **Asdale Dynamics, LLC** (Indiana, formed October 2026). It follows
the same plain-English, step-by-step, never-condescending style as his book
*The Massive AI Manual* and hub site dylanasdale.github.io: AI explained "like a
friend would."

It is for anyone who plays D&D, Pathfinder, Call of Cthulhu, board games, or
any tabletop game and wants a helpful, free AI assistant at the table — no
coding required, no technical background assumed.

## How to read it

No server, no install, no account is needed to read the guide itself.

- **Markdown:** Start with `docs/00-intro.md`, or jump to the section you need.
- **HTML:** Open `site/index.html` in any web browser. Everything works offline.
- **Worksheets:** Open a worksheet file in your browser and print (Ctrl+P /
  Command+P). Print styles hide navigation and color so the sheets print cleanly
  on plain paper.

## Try your first prompt

Copy and paste this into any free AI chat (Claude, Gemini, Copilot, or a local
model such as Ollama):

> I am new to tabletop roleplaying games. I want to make a character for a
> fantasy game. Please ask me five short questions, one at a time, to help me
> build a character I will enjoy playing. Keep the language simple and
> encouraging.

That is all it takes to start.

## Privacy

See `docs/09-privacy-and-safety.md` and `site/privacy-and-safety.html`. This
guide never asks for your personal data and contains no API keys or secrets.
Never paste real names, addresses, phone numbers, passwords, or anyone else's
private information into an AI chat.
